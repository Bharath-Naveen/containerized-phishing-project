# Model card: phishguard Layer-1 URL model (XGBoost)

Generated by `phishguard evaluate` on 2026-09-30T23:51:06+00:00 at commit `618516e321`. All numbers come from `metrics/results/evaluation.json`.

## What it is

An XGBoost classifier that scores a URL's text (no page visit) for phishing. It is Layer 1 of a larger system: its score is one input to a deterministic Evidence Adjudication Layer that also weighs live-page, HTML and brand evidence before giving a verdict. It should not be used on its own to block sites.

## Intended use

- Fast first-pass triage of URLs inside the phishguard dashboard.
- Research and demonstration of explainable phishing detection.

Not intended for: blocking or allow-listing without the adjudication layer, or for URLs whose meaning depends on page content (for example a compromised legitimate site).

## Training data

- Kaggle `harisudhan411/phishing-and-legitimate-urls`: 822,010 URLs, deduplicated to 794,563, plus 823 curated legitimate homepages. No timestamps, so drift over time cannot be measured from this data.
- Split by registered domain: 600,743 training and 147,702 test URLs, no domain in both.
- Evaluation URLs (curated suites, official brand URLs, PhishStats URLs) are removed from training.
- 54 URL and host features, computed scheme-neutral (the model never sees http vs https, which is an artifact of this dataset).

## Performance

- Held-out test: F1 0.801 (95% CI 0.799 to 0.803), ROC-AUC 0.880, PR-AUC 0.849, precision 0.772, recall 0.832, false-positive rate 21.3%. Majority-class baseline: F1 0.000, ROC-AUC 0.500.
- Real official brand URLs (not in training): Layer 1 flags 40.4% of 136; the dashboard labels 0.0% as likely_phishing (the rest go to uncertain).
- Real PhishStats phishing URLs (hosts not in training): Layer 1 flags 81.0% of 284.

## Limitations

- The legitimate side of the training data does not look like many modern official sites, so the URL model alone over-flags them. The adjudication layer is what keeps those from becoming phishing verdicts.
- URL-only features cannot see compromised legitimate domains or page content.
- The Kaggle data has no dates; performance on future phishing campaigns is unmeasured beyond the PhishStats sample.
- Without live capture the system rarely returns likely_legitimate; that is by design.

## Reproduce

```
phishguard train --full
phishguard evaluate --with-tests
```
